## 1. 이 서비스의 본질

이 서비스의 핵심은 '수묵화 느낌의 브러시'가 아니다.

실제 구조는 다음 세 계층의 상호작용이다.

```
사용자 입력
  ↓
붓의 물리 상태
  ↓
붓털별 먹/수분 전달
  ↓
종이 셀의 물/안료 상태
  ↓
섬유 방향 확산 + 건조 + 가장자리 축적
  ↓
최종 수묵 질감
```

즉 시각적 결과를 직접 그리는 것이 아니라 **재료의 행동을 시뮬레이션한 결과가 화면이 되는 구조**다.

## 3. 붓 모델

화면 설명에 따르면:

- 붓털 72가닥
- 각 털은 8개 입자의 체인
- 1/240초 단위 위치 기반 동역학(PBD)
- 길이 제약
- 원래 형태로 돌아가는 탄성
- 젖은 털끼리 모이는 힘
- 종이와의 마찰/퍼짐

### 왜 중요한가

보통 Canvas 브러시는 한 포인터 경로를 굵은 선으로 바꾸는 방식이다.

여기서는 붓끝이 하나의 점이 아니라 **다수의 가닥으로 이루어진 변형 가능한 묶음**이다.

따라서 자연스럽게 다음 효과를 얻는다.

- 획 시작 시 털이 눌리며 넓어짐
- 방향 전환 시 붓끝이 뒤늦게 따라옴
- 속도에 따른 털 갈라짐
- 수분 감소 시 갈필
- 압력 변화에 따른 획 폭의 비선형 변화
- 붓을 비틀거나 꺾을 때 불규칙한 에지

이 부분이 수묵 감성을 결정하는 핵심이다.

## 4. 먹 모델

화면 설명상 각 붓털은 **독립적인 먹 보유량**을 갖는다.

붓 전체에는 별도의 저장량이 있으며, 각 털이 여기서 먹을 공급받는다.

```
brushReservoir
  ├─ bristle[0].ink
  ├─ bristle[1].ink
  ├─ ...
  └─ bristle[n].ink
```

저장량이 줄면 일부 털부터 마르고, 모든 털이 동일하게 종이에 닿지 않기 때문에 갈필이 생성된다.

### 놀아트에서 특히 가져올 가치가 큰 점

**갈필을 별도 브러시 텍스처로 만드는 대신 상태의 결과로 발생시키는 것.**

예:

```ts
deposit = contact
        * bristleInk
        * pressure
        * paperContact
        * localFiberHeight
```

먹이 부족하면 `bristleInk`가 낮은 털들이 탈락하면서 자연스럽게 빈 틈이 생긴다.

## 5. 종이 모델

화면 설명:

- 약 2048×1152 격자
- 한 셀 약 0.31 mm
- GPU compute shader
- 물은 이웃 셀로 이동
- 섬유 방향으로 더 잘 흐름
- 안료는 물을 따라 이동
- 수분이 증발하면 안료가 남음
- 가장자리에 안료가 축적됨

이것은 단순 blur가 아니다.

### 셀 상태 예시

각 종이 셀을 최소 다음 상태로 볼 수 있다.

```ts
type PaperCell = {
  water: number
  pigment: number
  fixedPigment: number
  fiberAngle: number
  absorbency: number
  height: number
}
```

### 확산

등방성 확산이 아니라 종이 섬유 방향을 따르는 **anisotropic diffusion**이 핵심이다.

```
flow(i → j)
= max(0, water_i - threshold_j)
× directionalFiberWeight
× wetness
```

### 먹 테두리

젖은 영역이 마르는 경계에서 안료가 집중되면 실제 먹 번짐에서 보이는 진한 가장자리가 만들어진다.

따라서 '번짐'은 Gaussian blur보다 **water front + pigment transport + evaporation**으로 접근해야 한다.

---

## 6. 종이와 먹의 프리셋

확인되는 조합:

- 송연먹 · 한지
- 주묵 · 선지
- 금니 · 감지
- 송연먹 · 백지

중요한 점은 색상 테마를 바꾸는 것이 아니라 **재료 조합을 하나의 preset으로 묶었다는 점**이다.

놀아트에서도 다음처럼 구성하는 편이 맞다.

```ts
type MediumPreset = {
  pigment: PigmentProfile
  paper: PaperProfile
  brush?: BrushProfile
}
```

예:
- 먹 + 한지
- 옅은 먹 + 장지
- 주묵 + 선지
- 아동용 간소화 한지

---

## 7. 다시 쓰기 / 타임랩스

특이한 점은 최종 비트맵만 저장하는 것이 아니라 **붓 입력을 물리 스텝 단위로 기록**하고 빈 종이에서 재연산할 수 있다는 점이다.

이 구조는 놀아트에 매우 유용하다.

### 저장 모델

```ts
type StrokeSample = {
  t: number
  x: number
  y: number
  pressure: number
  tiltX?: number
  tiltY?: number
  toolState: {
    ink: number
    water: number
    brushSize: number
  }
}
```

### 교육적 가치
- 작품 제작 과정 재생
- 교사의 시범 획 재현
- 학생 작품 과정 관찰
- 타임랩스 자동 생성
- 결과보다 과정 중심 평가 가능

## 8. UI/UX에서 배울 점

### 8.1 디지털 기능을 실제 재료의 언어로 번역

| 그래픽 앱 개념 | 이 서비스의 번역 |
|---|---|
| wetness | 물 묻히기 |
| decrease wetness | 물기 빼기 |
| pigment load | 먹 찍기 |
| pigment concentration | 벼루 문지르기 |
| canvas reset | 새 종이 |

놀아트에서도 이 접근을 유지하는 것이 좋다.

### 8.2 고급 기능은 숨기지 않되 맥락 속에 둔다
- 그래픽 품질
- 붓털 골격 보기
- 배속
- 일시정지
- 확대/축소
- 전체화면

'미술 도구'와 '시뮬레이션 디버그/고급 기능'이 분리되어 있다.

### 8.3 실제 화선지 느낌을 살리는 화면
- 넓은 여백
- 낮은 채도
- 도구가 캔버스 주변에 위치
- UI가 캔버스보다 튀지 않음

놀아트의 기존 친근한 UI를 모두 수묵 스타일로 바꾸기보다는 **그리기 모드 안에서만 몰입형 작업실 UI**로 전환하는 편이 적절하다.

## 9. 성능 설계

이 서비스는 WebGPU를 명시적으로 사용하고, 고품질/기본 품질을 구분한다.

이 점은 놀아트 적용 시 그대로 복제하기보다 **3단계 품질 구조**가 낫다.

### 권장

#### Lite
- Canvas2D/WebGL
- 16~24 bristles
- 512~1024 diffusion texture
- 간소화 확산
- 저사양 태블릿 대응

#### Standard
- WebGL2 또는 WebGPU
- 32~48 bristles
- 1024~1536 texture
- anisotropic diffusion

#### High
- WebGPU
- 64~72+ bristles
- 2048 texture
- 실시간 pigment transport

초등학교 태블릿 환경을 고려하면 **WebGPU-only 구현은 부적절**하다.

## 10. 놀아트가 그대로 가져오면 안 되는 부분

### 10.1 지나치게 사실적인 물리 시뮬레이션
교육용 서비스의 목표는 재료과학 시뮬레이터가 아니다.

72×8 PBD를 그대로 적용하면:
- 코드 복잡도 증가
- 배터리/발열
- 기기 편차
- 오류 가능성
- 수업 중 로딩/성능 문제

가 생긴다.

### 10.2 기능 과밀
현재 놀아트는 테셀레이션, 협동화, 작품 수집/전시 등 여러 활동을 포괄한다.

수묵화 모드 안에만 별도 도구 체계를 넣고, 서비스 전역 UX를 이 방식으로 바꾸면 안 된다.

### 10.3 원본 UI/그래픽의 직접 모사
학습해야 할 것은 **행동 모델과 설계 원리**이며 시각적 배치·명칭·그래픽을 그대로 복제하는 것은 피해야 한다.

## 11. 핵심 transferable patterns

가장 가치가 높은 순서:

1. **물/먹/종이를 독립 상태로 모델링**

3. **먹 고갈 → 갈필 자동 발생**
4. **종이 방향성 확산**
5. **건조 경계의 pigment accumulation**
6. **물리 파라미터를 실제 미술 행위로 번역한 UX**
7. **입력 이벤트 기반 replay**
8. **재료 preset**
9. **성능 등급 선택**
10. **과정 자체를 관찰할 수 있는 시각화**

## 12. 결론

놀아트에 가져와야 할 것은 '검은 먹 텍스처'가 아니라 다음 관계다.

> **붓이 먹과 물을 품고 → 종이에 닿으며 → 종이가 그것을 흡수하고 → 시간이 지나며 번지고 마르는 구조**

이 네 단계만 제대로 만들면, 훨씬 단순화된 구현으로도 수묵화 특유의 생동감을 얻을 수 있다.
